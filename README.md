# iris_chart_story
# Iris Dataset Chart Story

## Overview
This project uses the Iris dataset to compare flower measurements across three species: Iris-setosa, Iris-versicolor, and Iris-virginica.

## Charts
The charts compare the average petal length, sepal length, and petal width for each species.

## Key Findings
Iris-virginica has the largest average measurements, Iris-setosa has the smallest, and Iris-versicolor falls between them.

## Tools
- Microsoft Excel

## Learning Outcome
This exercise provided practice in summarizing data, creating charts, and communicating findings with a short data story.
